# Support

## Before opening an issue

1. Read the [README](README.md), [integration guide](docs/INTEGRATIONS.md), and
   [API reference](docs/API.md).
2. Confirm the behavior on the latest release or `main`.
3. Run `npm run check` and the smallest relevant test or example.
4. Remove credentials, customer data, and private artifacts from logs.

## Bug reports

Use the bug report form and include:

- version or commit;
- runtime profile;
- operating system and Node.js version;
- PostgreSQL and Docker versions when applicable;
- minimal reproduction;
- expected and observed behavior.

## Questions

Use a GitHub discussion when discussions are enabled. Until then, open a
focused issue only when the documentation does not answer the question.

## Security

Do not open a public issue for a vulnerability. Follow
[SECURITY.md](SECURITY.md).

## Support level

The latest 1.x release receives best-effort security and critical correctness
fixes. Stable support covers the bounded profile in
[Stability and Compatibility](docs/STABILITY.md).

Older 0.x alpha releases are unsupported after 1.0.0. This project does not
include a commercial support commitment, uptime SLA, hosted control plane, or
managed cloud account.
